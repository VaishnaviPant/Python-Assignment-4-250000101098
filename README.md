## Overview

This repository contains the Python programs prepared for **Assignment 4** as part of the B.Tech Computer Science Engineering coursework.

The assignment consists of 50 Python programs covering built-in functions, mathematical functions, user-defined functions, function arguments, return statements, variable scope, modules, and packages.

## Topics Covered

The assignment focuses on the following Python programming concepts:

1. Python built-in functions
2. Mathematical functions using the `math` module
3. User-defined functions
4. Function arguments and return statements
5. Positional, keyword, default, and variable-length arguments
6. Local and global variables
7. String and list operations using functions
8. Creating and importing user-defined modules
9. Different module importing techniques
10. Standard library modules such as `math` and `random`
11. Creating and using user-defined packages

## Execution Instructions

### Prerequisites

- **Programming Language:** Python
- **Python Version:** Python 3.8 or higher
- **Code Editor:** Visual Studio Code (VS Code)
- **Dependencies:** No external libraries are required for the listed programs. The assignment uses Python's standard library and user-defined modules.

### Steps to Run

1. Install Python on your system.
2. Open the repository folder in VS Code.
3. Open the terminal in the repository directory.
4. Run the required Python program using the command:

```bash
python Q01.py
```

On systems where Python 3 is invoked separately, use:

```bash
python3 Q01.py
```

Replace `Q01.py` with the required question file, such as `Q02.py`, `Q03.py`, or any other question number.

Programs that require input will ask for the necessary values in the terminal.

**Important:** For questions involving user-defined modules and packages, make sure their supporting files and folders are present in the correct directory structure before execution.
